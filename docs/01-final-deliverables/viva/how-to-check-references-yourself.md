# How to Check the Report's References Yourself

For each reference, copy the search text (or link) below. What comes up should match the "should show" line. Numbers match the report's own reference list [1]–[18], ordered by first appearance in the text (IEEE style). If anything doesn't match, tell me — don't edit the LaTeX yourself.

1. **ANSI/ASHRAE Standard 55-2023**
   Search: `ANSI ASHRAE Standard 55 Thermal Environmental Conditions for Human Occupancy`
   Should show: a real ASHRAE standard by that name (ashrae.org or a standards store).

2. **ASHRAE Position Document on Indoor Carbon Dioxide (2025)** (CO2 threshold source)
   Link: https://www.ashrae.org/file%20library/about/position%20documents/pd-on-indoor-carbon-dioxide-english.pdf
   Should show: a PDF from ashrae.org, Board-approved Feb 12, 2025, containing the sentence "ANSI/ASHRAE Standard 62.1 does not provide a limit value for indoor CO2."

3. **OSHA Technical Manual, Section III: Chapter 2** (humidity range source)
   Link: https://www.osha.gov/otm/section-3-health-hazards/chapter-2
   Should show: a page on osha.gov containing the phrase "Humidity control in the range of 20%-60%."

4. **WHO Global Air Quality Guidelines (2021)**

   Should show: a page on who.int.
